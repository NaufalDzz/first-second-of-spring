**The First Second of Spring** — a cosmic seed blooming into a living universe:
the very first instant of a new season, where a single seed cracks open and
unfolds into galaxies, light and growth.

## About the artwork

- The input image `artwork.jpg` was generated by ChatGPT's built-in image
  generation tool (image_gen). It was not drawn or generated by this program.
- Technical processing only: it was resized and encoded with ImageMagick into a
  1024×1024 JPEG (815,432 bytes, SHA-256
  `161dd18ceb5f22e03c69c4bb133fdc8b18116ba7449bb1e4e749be0676e1b3ac`).

## How it works

`main.py` uses only the Python standard library and runs fully offline. It
finds `artwork.jpg` next to itself, checks that it is 1..1,048,576 bytes and a
complete JPEG (SOI `FFD8` / EOI `FFD9` markers), then writes the exact same
bytes to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`). The write is
atomic (temp file, fsync, rename) and verified by reading it back, so every run
produces byte-identical output. The file keeps its JPEG content; its magic
bytes, not the `.png` name, identify the format. Errors are reported on stderr
with exit code 1 and leave no partial file.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
